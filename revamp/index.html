Destinations

Phases (Build Order)

Each phase maps a destination to a dispatch time. A destination needs at least one phase before loads can be entered for it. Reorder & set times on the dashboard.

Load Blending

Assign loads to two locations in an alternating pattern instead of all of one then all of the other. The optimizer gives the chunk size to the first location, then the same to the second, and repeats until one runs out — then fills the rest with whatever remains. Example: chunk 2 = 2 Columbus, 2 Dothan, 2 Columbus, 2 Dothan…

Receiver Windows

Set each destination's receiving hours. Deliveries outside the window get a plan quality warning and are deprioritized in the optimizer. Leave blank for no constraint.

Operational Settings
Optimizer Tuning

These apply immediately and re-generate the plan. No need to click Save Settings.

Balance Driver Hours
Evens out hours across drivers. Off = strictly dispatch loads in build order (everyone takes the earliest-built loads first).
Protect Windows
Prefer a truck that hits the receiver window over a higher-priority one that would deliver late. On by default — toggle off to compare plans.
Rescue Stranded Loads
Never strand an internal-only load: yield an overflow load to the outside carrier to free a driver for it. On-time & DOT are still enforced.
Protect Home Return
Don't over-load a domicile driver so late that their home run gets stranded past midnight. Pair with Rescue Stranded Loads so the displaced load still gets covered.
